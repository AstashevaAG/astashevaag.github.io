# Фоторедактор

Веб-приложение для работы с изображениями. Поддерживает загрузку изображений в форматах PNG, JPG и GrayBit-7.

## Функциональность

- Загрузка изображений в форматах PNG, JPG и GrayBit-7
- Отображение изображений на холсте
- Отображение информации о изображении (ширина, высота, глубина цвета)
- Поддержка собственного формата GrayBit-7 для изображений в оттенках серого

## Описание формата GrayBit-7

GrayBit-7 - это формат изображений в оттенках серого без сжатия, использующий 7 бит на пиксель для значений в оттенках серого. 8-й бит может использоваться для двоичной маски.

### Структура файла

Файл GrayBit-7 состоит из двух основных частей: заголовка и данных изображения.

#### Заголовок (12 байт)

- Сигнатура (4 байта): 0x47 (G), 0x42 (B), 0x37 (7), 0x1D (разделитель)
- Версия (1 байт): 0x01
- Флаги (1 байт): Бит 0 - флаг маски (0 = маски нет, 1 = маска присутствует)
- Ширина (2 байта): 16-разрядное целое число без знака в сетевом порядке байтов
- Высота (2 байта): 16-разрядное целое число без знака в сетевом порядке байтов
- Зарезервировано (2 байта): 0x0000

#### Данные изображения

Данные изображения следуют сразу за заголовком. Каждый пиксель хранится в виде одного байта со следующей битовой структурой:

- Биты 6-0: Значение в оттенках серого (0-127)
- Бит 7: Бит маски (если в заголовке установлен флаг маски)

## Запуск проекта

```bash
# Установка зависимостей
yarn install

# Запуск в режиме разработки
yarn dev

# Сборка проекта
yarn build

# Предпросмотр собранного проекта
yarn preview
```
